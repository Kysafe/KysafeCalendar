# Calendar — tapeta kalendarzowa do Wallpaper Engine

Interaktywna tapeta z kalendarzem, planem wydarzeń i zmiennymi tłami. Projekt zawiera pełny interfejs po polsku i angielsku. Wybierz gotową paczkę:

**[Otwórz tapetę w Steam Workshop](https://steamcommunity.com/sharedfiles/filedetails/?id=3827979849)**

- [Pobierz paczkę polską (ZIP)](release/Calendar-Wallpaper-PL.zip) — uruchamia się po polsku.
- [Pobierz paczkę angielską (ZIP)](release/Calendar-Wallpaper-EN.zip) — uruchamia się po angielsku.

Język można zmienić w dowolnej chwili w **Settings → Language / Ustawienia → Język**. Paczki zawierają wszystkie pliki tapety i folder `assets`.

## Instalacja w Wallpaper Engine

1. Pobierz i rozpakuj wybrany plik ZIP.
2. W Wallpaper Engine wybierz **Create Wallpaper** i przeciągnij do okna plik `index.html` z rozpakowanego folderu.
3. Zaimportuj projekt jako tapetę typu **Web**.

## Funkcje

- Widoki kalendarza: Grid, Minimal, Cards, 3-day cards, Week, Agenda, Compact, Bento i Editorial.
- Import wydarzeń z pliku `.ics` lub planu JSON; eksport planu do JSON.
- Dostosowywane kolory, tła, układ, czcionka i położenie paska.
- Obsługa wielu teł, obrazów oraz filmów WebM/Ogg; oddzielne tła dla widoku z kalendarzem i bez niego.
- Ustawienia dostępne w panelu właściwości Wallpaper Engine.

Przykładowe zdjęcia w `assets/` pochodzą z Unsplash i są udostępnione na licencji Unsplash: [Pascal Brändle](https://unsplash.com/photos/sunlight-breaking-through-mountain-peaks-at-dawn-tpxy36Pe8qU/) i [Kajetan Sumila](https://unsplash.com/photos/snow-covered-mountain-during-night-time-qnnQc5OjiSM).

## English

An interactive calendar wallpaper for Wallpaper Engine, with event planning and customizable backgrounds. The interface supports Polish and English. Choose a ready-to-install package:

**[Open the wallpaper in Steam Workshop](https://steamcommunity.com/sharedfiles/filedetails/?id=3827979849)**

- [Download the Polish package (ZIP)](release/Calendar-Wallpaper-PL.zip) — starts in Polish.
- [Download the English package (ZIP)](release/Calendar-Wallpaper-EN.zip) — starts in English.

You can switch languages at any time under **Settings → Language**. Each package includes all wallpaper files and the `assets` folder.

### Install in Wallpaper Engine

1. Download and extract the ZIP you want.
2. In Wallpaper Engine, choose **Create Wallpaper** and drag `index.html` from the extracted folder into the window.
3. Import it as a **Web** wallpaper.

### Features

- Calendar layouts: Grid, Minimal, Cards, 3-day cards, Week, Agenda, Compact, Bento, and Editorial.
- Import events from `.ics` or JSON; export your plan as JSON.
- Customize colors, backgrounds, layout, font, and dock position.
- Multiple image and WebM/Ogg video backgrounds, with separate scenes for calendar and no-calendar modes.
- Wallpaper Engine Properties support.
